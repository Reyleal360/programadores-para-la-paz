Plataforma Juvenil de Participación

Proyecto académico para aprender participación juvenil, transparencia, control ciudadano y trazabilidad mediante herramientas digitales.

Propósito del proyecto

Esta plataforma se construirá progresivamente como ejercicio pedagógico para comprender cómo la tecnología puede apoyar procesos comunitarios de participación y organización.

Advertencia pedagógica

Este proyecto no corresponde a una elección real, no recolecta datos personales reales y no debe utilizarse para hacer acusaciones.

Transparencia y rutas de control electoral

La Ley 1712 de 2014 garantiza el acceso a información pública en Colombia. La transparencia fortalece la confianza ciudadana. Documentar una posible irregularidad no significa acusar: es importante diferenciar entre hecho, duda, sospecha, evidencia, reporte y acusación.

  • MOE – Misión de Observación Electoral
  • Personería – Protección de derechos ciudadanos
  • CNE – Consejo Nacional Electoral
  • Fiscalía – Para posibles conductas delictivas
  • URIEL – Unidad de Recepción Inmediata para la Lucha contra la corrupción
